# LORGUS

Литературная dark-fantasy RPG/RP-платформа.

## С чего начинать

Если ты впервые открываешь этот репозиторий или продолжаешь работу после другого чата, сначала читай:

**[LORGUS_CHECKLIST.md](./LORGUS_CHECKLIST.md)**

Это главный файл состояния проекта. В нём находятся:
- что такое LORGUS;
- архитектура;
- игровой канон;
- что уже реализовано;
- что осталось;
- известные проблемы;
- текущая точка остановки;
- правила продолжения работы.

Технические файлы `.agent/*` и `AGENTS.md` дополняют мастер-чеклист, но не заменяют его.
