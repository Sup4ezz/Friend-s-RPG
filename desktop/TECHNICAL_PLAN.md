# LORGUS Desktop — технический план и проверяемые критерии

Дата: 2026-10-26
Статус: прототип в отдельной ветке; production не изменён.

## Подтверждённая исходная архитектура

- Репозиторий: `Sup4ezz/Friend-s-RPG`, основная ветка `main`.
- Текущий клиент: SPA на vanilla JavaScript/CSS/HTML; основной entrypoint `app.js`, стили `style.css` и `src/**`.
- В `app.js` Supabase JS v2 загружается через jsDelivr ESM.
- Конфигурация фронтенда читается из статического `/config.json`; там Supabase URL и publishable key. Это публичная клиентская конфигурация, не service-role secret.
- Production deployment workflow в репозитории настроен на Cloudflare Workers при push в `main`. Ветка прототипа не запускает этот workflow, поскольку trigger ограничен `main`.
- Supabase project ID `dxdxnttpznoekaiecrlv`, состояние ACTIVE_HEALTHY; проект имеет действующие таблицы персонажей, заявок, присутствия RP, сообщений, инвентаря и почты, а также Edge Functions для Telegram/летописи.
- Уже есть Android admin app infrastructure в корневом `package.json` с Capacitor. Поэтому настольный клиент размещён в отдельном каталоге `desktop/` и не меняет корневой package manifest.
- Текущий прототип изолирован: не обращается к production-сайту или Supabase и не меняет игровые данные.

## Архитектурное решение для первого прототипа

Первый безопасный вертикальный срез — Electron desktop shell для Windows 10/11 x64. Это позволяет получить проверяемое окно и установщик, используя существующие веб-технологии. Electron выбран как стартовая оболочка, не как окончательное решение о движке для будущих интерактивных сцен. По мере развития можно оценить Godot для отдельных игровых сцен, если реальная потребность в управляемом 2D/3D мире оправдает второй runtime.

Обязательные ограничения:
- renderer загружает только локальный HTML;
- `nodeIntegration: false`, `contextIsolation: true`, `sandbox: true`;
- нет service-role ключей, встроенных секретов или привилегированных API;
- нет соединения с Supabase до отдельного этапа;
- сайт и данные остаются рабочим fallback во время разработки.
