# LORGUS Desktop — клиент Windows в разработке

Отдельное приложение Electron для Windows 10/11 x64. Оно не заменяет production-сайт и пока не переносит игровой кабинет целиком.

## Что уже реализовано в прототипе

- Полноэкранная тёмно-фэнтезийная заставка и экран входа.
- Локальная сборка renderer и SDK Supabase; при запуске не нужен CDN.
- Вход через существующую схему LORGUS: логин преобразуется в тот же синтетический email, что и в веб-клиенте.
- Анимация голубя, письма и пера запускается только после подтверждённой успешной авторизации.
- Кабинет, карта, персонажи и архив пока являются визуальными заглушками — реальные игровые данные ещё не подключены.
- Electron renderer изолирован: `nodeIntegration: false`, `contextIsolation: true`, `sandbox: true`.

## Требования для разработчика

- Node.js 22 и npm
- Полный клон репозитория, потому что сборщик читает публичную клиентскую конфигурацию из корневого `config.json`.

## Запуск в режиме разработки

Из каталога `desktop`:

```powershell
npm install
npm start
```

Команда запуска собирает `renderer/app.bundle.js` и `renderer/config.generated.js` локально перед открытием Electron. В приложение включается только Supabase URL и publishable client key из корневого конфига. Service-role ключи не используются.

## Сборка установщика Windows

```powershell
npm run dist:win
```

Файл установщика будет создан в `desktop/dist/`. CI автоматически проверяет синтаксис, собирает renderer и создаёт предварительный NSIS-установщик. Это пока не финальный брендированный релиз.

## Что ещё не проверено / не готово

- Не выполнен визуальный запуск приложения на реальном Windows ПК в рамках этой задачи.
- Вход ещё нужно проверить на отдельной тестовой учётной записи.
- Нет реальных экранов персонажей, карты, RP, инвентаря и административных функций.
- Установщик пока без финальной иллюстрации/брендированных экранов и не проходил проверку на чистой Windows.
- Production-сайт, схема Supabase, RLS, Edge Functions и пользовательские данные не изменялись.
