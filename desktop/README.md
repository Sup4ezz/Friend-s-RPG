# LORGUS Desktop — прототип клиента Windows

Это изолированный прототип настольного клиента. Он **не заменяет production-сайт** и пока не подключается к Supabase: кнопки игровых разделов демонстрируют навигацию оболочки, а не реальные игровые данные.

## Требования

- Windows 10/11 x64
- Node.js LTS и npm для сборки разработчиком
- При запуске готовой сборки Node.js пользователю не нужен

## Запуск в режиме разработки

Из каталога `desktop`:

```powershell
npm install
npm start
```

## Сборка установщика Windows

```powershell
npm run dist:win
```

Результат ожидается в `desktop/dist/`. Сборка пока не запускалась в этой задаче; до распространения необходимо проверить её на чистой Windows 10/11.

## Границы безопасности прототипа

- Отдельное окно Electron; production не открывается и не изменяется.
- `nodeIntegration: false`, `contextIsolation: true`, `sandbox: true`.
- Renderer загружается из локального файла.
- Нет токенов, секретов, доступа к файловой системе из renderer или вызовов Supabase.
- CSP ограничивает источники контента.
- Внешние ссылки по умолчанию не открываются из приложения.
