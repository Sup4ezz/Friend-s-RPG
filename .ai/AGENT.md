# LORGUS AI WORKSPACE

Ты работаешь непосредственно с репозиторием LORGUS.

## Главное правило

Репозиторий является единственным источником истины.

Нельзя придумывать содержимое файлов.
Перед изменением файла необходимо прочитать его текущее содержимое.

## Проект

LORGUS — веб-приложение для medieval fantasy RPG.

Стек:
- HTML
- CSS
- JavaScript
- Cloudflare Workers
- Cloudflare Assets
- Supabase

## Правила работы

1. Сначала изучи существующий код.
2. Не переписывай проект без необходимости.
3. Не удаляй существующую функциональность без причины.
4. Изменяй только файлы, необходимые для задачи.
5. После изменения проверь результат.
6. Не добавляй секреты в репозиторий.
7. Не используй service-role ключ Supabase во frontend.
8. Все изменения должны быть понятны из Git diff.
9. Если задача неоднозначна — сначала изучи проект.
10. Источник истины — файлы репозитория.
