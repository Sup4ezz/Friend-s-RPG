# Telegram-уведомления администрации LORGUS

Telegram подключён как дополнительный канал для администратора. Веб-админка и её журналы остаются на месте.

## События, которые отправляются

- новая заявка персонажа;
- каждое новое RP-сообщение игрока (посты администрации не пересылаются);
- использование предмета в RP-посте;
- передача предмета другому персонажу;
- передача валюты;
- специальная награда из лутбокса;
- изменение статуса заявки;
- отмена RP-поста администрацией.

Сообщения отправляются обычным текстом без HTML-разметки. Длинные тексты обрезаются. Если Telegram не настроен или временно недоступен, игровой запрос не ломается: событие остаётся в `public.lorgus_telegram_outbox`.

## Первичная настройка (токен не отправлять в чат)

1. В Telegram открой **@BotFather**, выполни `/newbot`, задай имя и username бота. Скопируй выданный токен, но никому его не отправляй.
2. Открой созданного бота и нажми **Start** (или отправь `/start`).
3. Узнай chat ID. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, подставив токен только в адресной строке. В ответе найди `message.chat.id`. После проверки не публикуй эту ссылку: токен входит в URL.
4. В Supabase Dashboard проекта открой **Edge Functions → Secrets** и добавь:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather;
   - `TELEGRAM_CHAT_ID` — твой личный chat ID;
   - `LORGUS_TELEGRAM_WEBHOOK_SECRET` — длинный случайный секрет, придуманный тобой.
5. Тот же секрет из третьего пункта сохрани в **Database → Vault** с именем `lorgus_telegram_webhook_secret`. Если удобнее через SQL Editor, выполни запрос, заменив значение на то же случайное значение, которое указал в Edge Function Secrets:

   ```sql
   select vault.create_secret(
     'ВСТАВЬ_СЮДА_СВОЙ_ДЛИННЫЙ_СЛУЧАЙНЫЙ_СЕКРЕТ',
     'lorgus_telegram_webhook_secret',
     'Shared secret for LORGUS Telegram event delivery'
   );
   ```

   Не используй буквальный текст-заполнитель из примера. Значение должно в точности совпадать в Vault и Edge Function Secrets. Сам токен Telegram в Vault класть не нужно — он хранится только в Edge Function Secrets.

6. Напиши в этом чате **«Telegram настроен»** — секреты присылать не надо. Я проверю конфигурацию без чтения значений секретов, отправлю тестовое сообщение и активирую накопившиеся события.

## Технические детали

- Edge Function: `lorgus-telegram-notify`.
- Входящие запросы защищены отдельным секретным заголовком; встроенная JWT-проверка отключена только для этой функции, поскольку её вызывает серверный триггер PostgreSQL.
- Очередь закрыта RLS и не доступна через клиентский API обычным игрокам.
- Для отправки накопленных событий используется `select public.lorgus_dispatch_pending_telegram_events(50);` после настройки секретов.
