# LORGUS

## Назначение

LORGUS — веб-приложение для средневековой fantasy RPG.

## Стек

- HTML
- CSS
- JavaScript
- Cloudflare Workers
- Cloudflare Assets
- Supabase

## Основные файлы

### index.html

Основная HTML-страница приложения.

### app.js

Основная клиентская логика.

### style.css

Стили интерфейса.

### worker.js

Cloudflare Worker.

### wrangler.toml

Конфигурация Cloudflare Wrangler.

## Правило

Перед изменением существующего кода AI должен изучить
текущее состояние репозитория.
