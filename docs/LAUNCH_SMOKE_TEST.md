# LORGUS — проверка перед запуском

Production: https://friend-s-rpg.staskarr23.workers.dev/

Эта инструкция нужна для ручной проверки в настоящем браузере. Отмечай пункт только если лично увидел ожидаемый результат. Не используй основного персонажа для тестов, которые тратят предметы или валюту.

## Подготовка

1. Открой Firefox/Chrome на компьютере и перейди по ссылке выше.
2. Открой инструменты разработчика: F12 → Console. Оставь консоль открытой.
3. Войди под обычным игроком, у которого есть одобренный персонаж. Не используй аккаунт администратора для проверки прав обычного игрока.
4. Если есть отдельный тестовый аккаунт с двумя одобренными тестовыми персонажами — используй его для передач и лутбоксов.
5. Если на любом шаге появилась красная ошибка в Console, скопируй весь текст ошибки и укажи номер шага. Не публикуй токены, cookies или значения из Storage.

## Тест 1. Вход и выбор персонажа

1. Обнови страницу через Ctrl+F5.
2. Войди в аккаунт.
3. Выбери одобренного персонажа.
4. Дождись загрузки карты мира.

Ожидаемый результат:
- вход не возвращает на страницу входа повторно;
- карта появляется, персонаж выбран;
- в Console нет красных ошибок;
- перезагрузка страницы не сбрасывает авторизацию.

Если вместо карты заглушка/пустой экран — остановись и запиши, что именно видно.

## Тест 2. Стрелки и возврат на карту

Проверяй по одному переходу; после каждого возвращайся на карту.

1. На карте нажми стрелку/пункт «Персонаж».
2. Убедись, что открылось досье персонажа.
3. Нажми верхнюю центральную стрелку возврата.
4. Убедись, что вернулась именно карта мира.
5. Повтори для «Письма».
6. Повтори для RP.
7. Повтори для «Лорбука».
8. После каждого перехода проверь, что можно снова открыть другой раздел.

Ожидаемый результат: ни один раздел не оставляет пустую страницу, не зависает и не возвращает в неправильный раздел; возврат из каждого раздела ведёт на карту.

## Тест 3. Лорбук

1. Открой «Лорбук».
2. Открой каждый доступный раздел/узел.
3. Нажми на несколько имён персонажей и вернись назад.
4. Обнови страницу, затем открой Лорбук снова.

Ожидаемый результат:
- список и тексты разделов загружаются;
- ссылки/карточки открывают ожидаемые материалы;
- после обновления Лорбук снова доступен;
- нет пустого содержимого из-за ошибки загрузки.

## Тест 4. RP и правило первого сообщения

Этот тест меняет игровое состояние тестового персонажа. Выполняй только если персонаж предназначен для тестов.

1. До первого RP-сообщения открой доступную локацию и прочитай историю.
2. Закрой чат, открой другую локацию и прочитай историю.
3. Вернись в первую локацию.
4. Отправь одно короткое тестовое сообщение, например «Проверка присутствия».
5. Попробуй открыть другую RP-локацию через карту/список.
6. Обнови страницу и снова открой RP.

Ожидаемый результат:
- до первого сообщения можно читать разные комнаты;
- простое открытие/чтение комнаты само по себе не фиксирует присутствие;
- после первого сообщения персонаж закреплён за своим текущим RP-пространством;
- другая локация блокируется или не даёт читать её историю;
- после обновления блокировка сохраняется;
- собственное сообщение появляется один раз, без бесконечной загрузки.

Если другое пространство открывается и показывает историю после первого поста — это блокер запуска, зафиксируй точный шаг.

## Тест 5. Ответ на сообщение и живое обновление

1. В текущей разрешённой комнате нажми «Ответить» на существующее сообщение.
2. Отправь короткий тестовый ответ.
3. Если доступен второй тестовый аккаунт, оставь комнату открытой под первым аккаунтом и отправь сообщение под вторым.

Ожидаемый результат:
- ответ отображает автора/цитируемое сообщение правильно;
- сообщение появляется один раз;
- новые сообщения появляются без ручной перезагрузки (допустима небольшая задержка опроса);
- в Console нет ошибок Supabase/RPC.

## Тест 6. Письма

1. Открой «Письма» → создание письма.
2. Проверь, что можно выбрать одобренного получателя.
3. Попробуй выбрать самого себя.

Ожидаемый результат: отправка самому себе запрещена с понятным сообщением.

4. Отправь тестовое письмо тестовому персонажу голубем.
5. Сразу проверь «Отправленные» и «Входящие» получателя.
6. До истечения срока доставки письмо не должно отображаться как доставленное/доступное во входящих.
7. После срока доставки (около 5 минут для голубя) проверь входящие и открытие/прочтение письма.
8. Если тестируешь курьера, ожидаемый срок — около 20 минут; не жди его, если не проверяешь именно курьерскую доставку.

Ожидаемый результат:
- успешная отправка видна в «Отправленных»;
- письмо не появляется у получателя раньше срока;
- после доставки письмо появляется во «Входящих» и отмечается прочитанным;
- интерфейс не заявляет о доставке мгновенно.

## Тест 7. Персонаж и инвентарь

1. Открой «Персонаж» и проверь портрет, имя, родину, титул и способности.
2. Открой снаряжение/инвентарь.
3. Проверь, что предметы и слоты отображаются без пустого экрана.
4. На тестовом персонаже проверь надевание и снятие обычного предмета, если он есть.

Ожидаемый результат:
- поля не подменяются данными другого персонажа;
- предмет после экипировки отображается в слоте;
- после снятия возвращается в инвентарь;
- перезагрузка не создаёт дубликаты и не теряет предмет.

## Тест 8. Админские действия

Выполняй отдельно под администратором.

1. Открой панель заявок и найди тестовую заявку.
2. Проверь одобрение тестовой заявки.
3. На другой тестовой заявке проверь запрос исправлений/отклонение с причиной.
4. Под обычным игроком проверь, что административные кнопки недоступны.

Ожидаемый результат:
- статусы меняются один раз и отображаются после обновления;
- отклонение без причины не проходит;
- обычный игрок не может выполнять административные действия.

Не меняй реальные заявки игроков ради проверки.

## Тест 9. Лутбокс (только тестовый персонаж)

Открытие лутбокса может потратить предмет, поэтому не делай этот тест на основном персонаже.

1. Открой лутбокс тестовым персонажем.
2. До открытия проверь, что видны содержимое и шансы наград.
3. Открой коробку один раз.
4. Сверь выпавшую награду с результатом и коллекцией персонажа.

Ожидаемый результат:
- анимация прокрутки/открытия проигрывается;
- фактическая награда совпадает с объявленной;
- валюта показывает правильную валюту королевства;
- титул/привилегия/особая награда сохраняется в коллекции;
- пустой пул не расходует коробку.

## Тест 10. Чёрный список

Только если уже есть отдельный тестовый заблокированный аккаунт.

1. Выйди из текущего аккаунта.
2. Войди под заблокированным тестовым аккаунтом.
3. Попробуй открыть прямую ссылку на карту и на другую страницу приложения.

Ожидаемый результат: на всех страницах появляется заглушка блокировки; обход через прямую ссылку невозможен.

## Тест 11. Мобильная раскладка

1. Открой сайт на телефоне или в инструментах разработчика включи режим мобильного устройства.
2. Проверь карту, «Персонаж», «Письма», RP и «Лорбук».
3. Прокрути каждый экран до конца и нажми основные кнопки.

Ожидаемый результат:
- текст и кнопки не выходят за экран;
- кнопки можно нажимать пальцем;
- карта/стрелки не перекрывают друг друга;
- страницы не требуют горизонтальной прокрутки для основного содержимого.

## Что прислать, если тест провалился

Для каждого провала пришли только:
- номер теста и шага;
- что ожидалось;
- что фактически появилось на экране;
- красную ошибку из Console, если она есть;
- скриншот экрана, если проблема визуальная.

Не присылай пароль, API-ключи, cookies или полный дамп Local Storage.
