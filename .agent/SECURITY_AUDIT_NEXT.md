# Следующие задачи аудита безопасности

- Проверить SECURITY DEFINER RPC по одной; не отзывать доступ у игровых функций без проверки вызовов и внутренних проверок.
- Исправить политику записи в `world_map_label_positions`: только администраторы.
- Проверить привязку `rp_messages_select_current_presence` к активному персонажу, а не только к `auth.uid()`.
- Включить leaked-password protection в настройках Supabase Auth после отдельного согласования.
- Настроить безопасные default privileges для будущих таблиц через роль-владельца.

Никакие production-изменения этим документом не выполняются.
