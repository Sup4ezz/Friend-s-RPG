# LORGUS — архитектурные решения

## 001 — GitHub является долговременным состоянием
Состояние автономной разработки хранится в репозитории. Новый чат не должен требовать восстановления всего контекста вручную.

## 002 — Доступ к ПК пользователя не требуется
Автономная разработка LORGUS должна работать через репозиторий и удалённые CI/agent runtime. Локальный Windows-ПК пользователя не является частью архитектуры агента.

## 003 — RP-присутствие является физическим состоянием
Персонаж может читать и писать только в том RP-пространстве, где он физически находится. Открытие карточки или экрана не означает вход.

## 004 — Дороги являются графом
Маршруты существуют только между явно указанными узлами. Нельзя автоматически создавать прямой маршрут между двумя локациями без канонического соединения.

## 005 — Геенна закрыта для игроков
Геенна не является доступной игровой локацией и не может использоваться как место рождения персонажа.

## 006 — Флуд не является RP
Флуд — отдельный player-level канал и не меняет физическое RP-присутствие персонажа.

## 007 — Письма не являются мгновенным каналом
Письма доставляются через игровой механизм голубя или курьера и имеют deliver_at. Клиентская задержка не считается достаточной серверной реализацией доставки.

## 008 — Не выносить секреты в репозиторий
Секретные ключи, токены и пароли никогда не добавляются в git.
